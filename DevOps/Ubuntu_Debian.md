1. What is Debian?
- Debian GNU/Linux is a free, open-source operating system developed by a community, combining the Linux kernel with system tools and applications.
- Debian is a Linux distribution
- Debian can be used for both desktop and server systems
2. What is Ubuntu?
- Ubuntu is a Linux distribution based on Debian. It is published by canonical and developed with community participation
- Ubuntu and Debian are related but they are separate diustributions
- Ubuntu desktop: Ubuntu for desktop use with graphical interface
- Ubuntu server: Ubuntu for server workloads
- Ubuntu core: Ubuntu designed for embedded and IoT devices
3. Package management
- Debian and Ubuntu use the Debian package system (.deb). APT manages software packages and their dependencies.
- apt update: refresh the package index
- apt install nginx: install nginx
- apt upgrade: upgrade installed packages
- apt remove nginx: remove nginx
- sudo allows an authorized user to run a command as another user, usually root
4. Terminal, shell, commands
- Terminal: An interface for entering commands and reading output
- Shell: A program that interprets commands
- Bash: A commonly used shell
